# Medical data workspace

Reserved for first-party structured educational content. No external clinical records, licensed text, guidelines or assets are seeded here. Source metadata and evidence provenance belong in `sources/SOURCE_REGISTRY.json`; every claim must remain `demo` or `needs-review` until the existing evidence and qualified-review gates are met. See [medical rules](../docs/MEDICAL_RULES.md) and [data schema](../docs/DATA_SCHEMA.md).
