# Attributions

No third-party asset has been imported through this registry, so there are currently no new asset attributions to display. The app's procedural geometry remains labeled as technical placeholder geometry. Existing software dependency notices remain governed by the dependency inventory and each dependency's license.

For future assets, preserve the creator/source name, exact asset title and source URL, license name and URL, required notice, modifications, source version and checksum. Keep attribution scoped to each asset instead of applying a collection's top-level notice indiscriminately. For CC BY-SA assets, preserve the applicable share-alike requirements; for any NC asset, review compatibility before use. Do not list an attribution as if it grants permission.

Actual imported media must first be recorded in [ASSET_REGISTRY.json](ASSET_REGISTRY.json) and pass [ASSET_POLICY.md](../docs/ASSET_POLICY.md).
