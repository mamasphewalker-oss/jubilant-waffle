# TCM research boundary

`catalog.ts` registers evaluated repositories, pinned revisions, code/data rights and integration decisions. Registration is not a dataset import or a medical endorsement. No candidate is approved to import data by default.

`contracts.ts` validates future normalized offline exports with Zod, stable IDs, provenance, typed relation domains and resolved endpoints. Database associations and computational predictions cannot be represented as clinical effects. Traditional descriptions remain separate from biomedical evidence. Unknown data rights, reference-only integrations and benchmark-only sources fail the import gate.

No upstream application, R/Python environment, graph database, dataset or model weights are bundled. No external fetch, automatic diagnosis, prescribing or LLM evaluation is enabled. See `docs/tcm-open-source-research.md` and `docs/tcm-integration-roadmap.md` before implementing any adapter.
