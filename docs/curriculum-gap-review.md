# 课程与功能缺口检查

检查日期：2026-10-12。对照用户目标检查 GitHub 仓库的已同步源码、课程页面、医学数据模型、路线图和 CI。本站服务医学生、住院医师、临床教师与中西医结合学习者；现代医学是主框架。以下是产品实现检查，不是医学审核。

| 缺口                       | 本次处理                                       | 当前边界                                  |
| -------------------------- | ---------------------------------------------- | ----------------------------------------- |
| 页面之间缺少系统课程入口   | 首页增加五阶段课程路径，连接六个学习页面       | 正常功能为原型，其余为课程框架            |
| 四类学习者没有不同任务     | 每阶段提供角色任务、学习目标                   | 没有账户、成绩或能力认证                  |
| 教师缺少讨论与反馈入口     | 增加讨论提示与学习者自查                       | 自查只在当前首页实例保留，离开/刷新后重置 |
| 通用医学对象缺少审查人要求 | 审查人加入通用模型与证据卡，已审查记录必须填写 | 不能代替具备资质的医学审核                |
| 日期仅验证字符串格式       | 审查/访问日期改为日历日期校验                  | 时间先后及指南更新仍需后续流程            |

## 五阶段目标

1. 人体正常功能：结构与功能、变量与单位、模型假设。
2. 疾病机制与药物作用：状态变化、研究关联、机制与临床证据的区别。
3. 临床诊断：现代医学评估、危险征象优先、检查局限与不确定性。
4. 规范治疗：指南适用范围、版本、原始推荐分级、安全与相互作用。
5. 患者病例推理：仅使用合成教学情境，整合证据、信息缺口与反思。

课程文案是原创教学设计；没有新增疾病机制、真实病例、药物疗效或剂量事实。中医任务单独强调传统教材与现代证据，保持补充层定位。课程数据位于 `src/curriculum`，展示与临时自查状态由独立组件持有。
