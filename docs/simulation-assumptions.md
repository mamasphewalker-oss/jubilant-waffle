# Cardiovascular teaching assumptions

No patient data, calibration or clinical prediction. All controls are sandbox values, not physiologic reference ranges.

CO (L/min) = HR (beats/min) × SV (mL/beat) / 1000. This is the definitional volume-per-time identity, written as an educational assumption. The factor 1000 converts mL to L. Example sandbox 70 × 70 / 1000 = 4.9 L/min does not describe a patient.

ΔP (mmHg) = CO × SVR with SVR in mmHg·min/L. This is a simplified lumped-resistance relation. It ignores central venous pressure, compliance, beat-to-beat dynamics, autonomic feedback and parameter coupling. It is not a measured or predicted blood pressure. No guideline, efficacy or clinical dose claim is made.

The chart sweeps HR 30–180 at fixed SV. Holding SV constant deliberately illustrates multiplication and is not a valid individualized physiologic response. SVR affects pressure gradient, not CO, in this intentionally decoupled model. No heart/pulse animation asserts actual anatomy.

Future scientific simulations require cited equations, expert review, validation data, uncertainty and explicitly named domains of validity.
